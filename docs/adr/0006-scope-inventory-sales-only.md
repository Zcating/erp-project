# 范围：只做商品主数据 + 采购/库存/销售域

本项目只覆盖 ERP 的进销存域与商品主数据：商品档案（主数据）、采购、库存、销售，外加退货、盘点、调拨，以及支撑它们的供应商与客户主数据。明确不做：财务记账、应收应付、总账、工资、生产制造、报表平台、税务、多租户 SaaS 平台、界面与前端。

**不做订单域**：本版本只有单据（入库单、出库单、退货单、盘点单、调拨单），不实现采购订单与销售订单。

**不做批次与效期**：库存不按批次记账，不管理保质期与到期日。商品档案里的保质期字段也一并省略。

商品档案的**外部数据源不进内核**：内核只维护「商品档案」实体本身，另提供 CSV/JSON 批量导入建档；第三方条码库对接留给业务方（其售价不可信、图片 URL 会过期，不适合直接入库）。

供应商与客户只做最简主数据（编码、名称、联系方式），不含价格表、信用额度。商品支持基本计量单位与辅助计量单位之间的换算，称重商品不在范围内。

## Consequences

- 「通用」指领域模型与业务不变量通用、可嵌入不同业务系统，不是「一套包含全部 ERP 功能的系统」。
- 成本结转只到「出库时结转成本、产出成本流水」为止，不产生会计凭证，也不出站给财务系统。
- 单据与库存行为是内核的全部职责边界；参考应用只是这些行为的 HTTP 外观。
- 库存上下限只用于告警，不阻断任何操作。
