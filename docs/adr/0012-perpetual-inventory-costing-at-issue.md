# 永续盘存制：出库时结转销售成本

本项目采用**永续盘存制**：入库时即按成本增加存货金额，出库时按计价方法算出发出成本并结转销售成本，每笔出入库当场记入库存流水。不采用定期盘存制（期末倒挤销货成本），也不采用零售业特有的售价金额法与毛利率法（平时按售价记账、期末分摊进销差价）。

理由：永续盘存制下库存金额实时准确、每笔单据的成本可追溯到流水；定期盘存制平时看不到成本、误差大，且本项目的核心是「库存流水可审计」，与倒挤模式相悖。《企业会计准则第 1 号——存货》第十四条允许发出存货计价采用先进先出法、加权平均法或个别计价法（本项目取加权平均，见 ADR-0007），并无「后进先出法」。

## Consequences

- 每张单据的过账与作废都在同一事务内同时写库存台账与库存流水，不存在「先出库、后算成本」的中间态。
- 成本结转的时点是**出库过账时**，不是发货时、不是开票时、也不是期末。
- 不实现期末进销差价分摊、跌价准备计提、期末成本重算。
