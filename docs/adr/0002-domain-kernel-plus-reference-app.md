# 交付物是「领域内核库 + 参考应用（Fastify API + TanStack Start 管理后台）」

本项目分三层交付：一层是不含界面与存储的**领域内核**（商品档案 + 进销存的模型与业务不变量，以库形式交付给业务方嵌入使用）；一层是用 Fastify 写的**参考 API**（把内核行为暴露成 HTTP 接口）；一层是用 TanStack Start 写的**最小管理后台前端**——商品档案维护、库存查询、单据过账/作废、库存流水查看——用来证明内核可用，并作为 e2e 的验收面。明确不做：多租户 SaaS 平台、行业模板、开箱即用的完整产品界面、复杂报表与工作流引擎。

## Consequences

- 内核不得依赖 HTTP、数据库或 UI；Fastify 与前端都只做装配与呈现。
- 前端只通过 Fastify API 访问数据（SSR 时由 server 侧请求 API），内核只有一条 HTTP 入口，不存在第二条「前端直连内核」的旁路。
- 验收标准按「用户看得见的行为」书写：UI 行为用 Playwright 断言，API 行为用 vitest 断言。
