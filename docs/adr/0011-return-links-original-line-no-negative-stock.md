# 退货必须引用原单据行并回冲原成本，禁止负库存

两件事绑在一起定：**退货单必须引用原单据行**（销售退货引用原销售出库单的行，采购退货引用原采购入库单的行），**任何出库动作都不得使账面库存变为负**。

理由：退货不引用原单就无法回答「退的是哪一批、当时结转了多少成本」，成本回冲失去依据，账就对不上；允许负库存则库存与成本失去意义（负成本无法定义），所以负库存一律拒绝。

## Consequences

- 单据行要能引用原单据行（`originalLineId`），且同一原单行的累计退货数量不得超过其已过账数量。
- 销售退货过账：库存增加，入库成本 = 原出库行已结转的成本（精确回冲）；采购退货过账：库存减少，按当前加权成本结转。
- 盘点盘亏与销售出库若会使库存为负，整单过账失败并报明确错误（不允许「先出负数以后补」）。
- 退货也遵守单据状态机（草稿 → 已过账 → 已作废），过账才有库存影响。
