# 库存量口径：账面、可用、在途

库存量对外只暴露三种口径：**账面库存**（某仓某商品当前在库数量）、**可用库存**（本版本等于账面库存）、**在途库存**（已调出未调入，归属于调拨单）。库存上下限只用于告警，不阻断操作。

理由：进销存系统里「库存」这个词最常见的歧义就是「账面 vs 可用 vs 在途」三套数混着说。本版本没有订单域，没有任何东西会预留库存，所以不引入占用/锁定/预留概念（加了也没有来源），可用库存等于账面库存；一旦以后接订单域，只需加一个「占用」扣减项，账面口径不受影响。

## Consequences

- 查询库存的接口必须显式区分口径字段（`onHand` / `available` / `inTransit`），不允许只返回一个叫 `quantity` 的数。
- 库存台账存的是账面数量与加权成本；在途不占任何仓库的库存，但携带成本。
- 禁止负库存（ADR-0011）作用于账面库存；在途数量同样不得为负。
