# 库存成本核算用移动加权平均

库存成本用**移动加权平均**：每次入库按「（原库存成本 + 本次入库成本）÷（原数量 + 本次入庫数量）」重算加权平均成本，出库时按当前加权平均成本结转。不做 FIFO、不做 LIFO、不做批次成本。理由：移动加权是零售与进销存场景的主流做法，单一成本口径不需要批次就能表达「一个 SKU 一个当前成本」；而 FIFO 必须配合批次记账，与「不做批次效期」的范围决定冲突。准则依据：《企业会计准则第 1 号——存货》第十四条允许先进先出法、加权平均法、个别计价法三种（未含后进先出法），移动加权平均属于「加权平均法」的月度实操口径。

## Consequences

- 精度与舍入规则见 ADR-0013（数量 3 位、单价 6 位、金额 2 位、统一 half-up、禁用浮点）。
- 加权平均的除法必须用十进制除法并按约定精度截断/舍入，舍入规则要写死在规格里（不得依赖数据库默认行为）。
- 退货成本按原单据行已结转的成本回冲，不按当前加权成本重算。
- 任何库存数量或成本的上限约束都由「同一仓库同一商品同一事务内串行」保证：Postgres 行级锁 + 单事务，代价是同 SKU 高并发串行。
